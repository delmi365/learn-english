# 高考英语冲刺 App（高三私人定制版）

一个**单文件、可离线使用**的高考英语学习网页 App。专为高三学生设计：英语基础约 80 分，目标冲刺本科。双击 `index.html` 即可使用，无需安装任何环境，所有学习数据保存在本机浏览器（localStorage）。

## 功能模块

| 模块 | 内容 |
|---|---|
| 首页 | 高考倒计时、学习打卡、每日任务、「80 → 105 分」得分拆解表 |
| 考情资源 | 2010–2026 四川高考英语卷种演变、试卷结构、各题型重点考点速查、可下载试卷的网站 |
| 背单词 | 288 个高考高频词 + 50 个短语动词；每词带音标、释义、**两句中英对照例句**、考点难点；闪卡 + 发音 + 艾宾浩斯复习（1/2/4/7/15/30 天）+ 生词本 + 单元测 |
| 学语法 | 10 章语法专题（动词时态、被动语态、定语从句、名词性从句、状语从句、非谓语动词、虚拟语气、倒装、主谓一致等），每章讲解 + 互动闯关 |
| 读短文 | 8 篇分级阅读（基础 / 提升 / 冲刺）+ 七选五 + 完形填空 + 读后续写，全部带答案解析 |
| 写作句型 | 30 句高分句型（应用文 15 句 + 读后续写 15 句），每天自动推送 |
| 往年真题 | **10 套真题题集（66 题 + 2 篇范文），全部按年份 + 卷种标注**：2025 新高考 II 卷语法填空全文、2025 读后续写真题（附官方范文）、2024 全国甲卷完形全文、2022 全国甲卷 / 乙卷语法拆解、2021 全国甲卷真题等；选择 / 填空作答，自动判分出解析，错题自动记录 |
| 升学政策 | 国家专项 / 地方专项 / 高校专项对比、民族地区加分、关键时间轴、近年本科批次线 |
| 设置 | 每日新词量调节、学习记录导出 |

## 考情背景

- 2010–2015：四川自主命题
- 2016–2020：全国 III 卷
- 2021–2024：全国甲卷
- **2025 年起：全国新高考 II 卷**（含读后续写）

## 本地使用

直接双击 `index.html`，或：

```bash
# 任选其一
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
```

## 部署到 GitHub Pages（可选，手机上也能学）

1. 将本仓库上传到 GitHub（仓库名随意，例如 `gaokao-english-app`）
2. 仓库页面 → **Settings** → **Pages**
3. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
4. 等约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零依赖、零构建、零网络请求（发音用浏览器内置 SpeechSynthesis）
- 响应式布局，手机 / 平板 / 电脑均可使用
- 学习进度、生词本、打卡记录均存于浏览器 localStorage，换设备不同步
